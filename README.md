# GatherTrailData

Starter database of mining and herbalism node locations (WoW Classic) for the
[GatherTrail](https://github.com/cleytoncl3/GatherTrail) addon. It is a load-on-demand data addon with no code:
GatherTrail loads it when you enter a zone.

**Install:** put the `GatherTrailData` folder in `Interface/AddOns` next to `GatherTrail`
(or install both from CurseForge).

**Credits and license:** the data comes from GatherMate2_Data (kagaro, Xinhuan, Nevcairiel;
Classic copy by Thurdi), GPL-2.0-or-later. See `NOTICE.txt` and `LICENSE`.
